> [!IMPORTANT]
>
> **Ophel Atlas** place la confidentialité au premier plan : stockage local par défaut, vos données restent sous votre contrôle.
>
> - **Stockage local par défaut :** réglages, prompts et données de gestion des conversations sont stockés dans le navigateur
> - **Sans compte :** aucune inscription nécessaire
> - **Permissions à la demande :** permissions optionnelles demandées uniquement si nécessaire, révocables à tout moment (voir la page Permissions de l’extension)
> - **Synchronisation WebDAV optionnelle :** utilisez votre propre WebDAV pour plusieurs appareils (contrôlable, portable)
> - **Export & sauvegarde :** export et migration pour éviter le verrouillage
>
> _Note : la prise en charge de sites d’IA spécifiques dépend du matching du site et des changements de structure des pages._

<summary><strong>Installation manuelle (Environnement hors ligne ou accès restreint)</strong></summary>


#### Extension de Navigateur

1. Téléchargez et décompressez depuis [Releases](https://github.com/urzeye/ophel/releases/latest)
2. Ouvrez la page de gestion des extensions du navigateur, activez le **Mode développeur**
3. Cliquez sur **Charger l'extension non empaquetée** et sélectionnez le dossier décompressé

#### Userscript

1. Installez [Tampermonkey](https://www.tampermonkey.net/)
2. Téléchargez le fichier `.user.js` depuis [Releases](https://github.com/urzeye/ophel/releases)
3. Faites glisser dans le navigateur ou cliquez sur le lien pour installer


</details>

<summary><strong>💻 Guide de développement local et de build</strong></summary>

<br>

**Prérequis**: `Node.js >= 18.x`, `pnpm >= 9.x`

```bash
# 1. Cloner le dépôt et accéder au répertoire du projet
git clone https://github.com/urzeye/ophel.git
cd ophel

# 2. Installer les dépendances
pnpm install

# 3. Lancer le serveur de développement (supporte le HMR pour l'extension)
pnpm dev

# ======== Build et Packaging ========

# Construire les versions de production pour chaque navigateur
pnpm build              # Construire l'extension Chrome
pnpm build:firefox      # Construire l'extension Firefox
pnpm build:all          # Construire pour toutes les plateformes principales

# Créer les archives de distribution (.zip)
pnpm package            # Packager l'extension Chrome à partir du build existant
pnpm package:firefox    # Packager l'extension Firefox à partir du build existant
pnpm package:all        # Packager toutes les plateformes

# ======== Développement de Script Utilisateur ========

pnpm build:userscript:local    # Construire le script utilisateur pour le débogage local
pnpm serve:userscript:assets   # Servir les ressources statiques localement
```

</details>
