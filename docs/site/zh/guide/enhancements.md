# 功能与设置参考

本页面涵盖 Ophel 三个主标签页之外的所有功能，同时作为设置页面的完整参考手册。

## 浮动快捷按钮

屏幕侧边有一组浮动按钮，与面板同侧显示。你可以：

- **拖拽** — 长按按钮组，拖到任意位置
- **自动折叠** — 5 秒不操作后收缩为药丸形；鼠标移近约 150px 时重新展开
- **透明度** — 在设置中调低透明度，让按钮淡入背景（设置 → 通用 → 快捷按钮）

默认按钮及功能：

| 按钮       | 作用                                |
| ---------- | ----------------------------------- |
| 面板       | 展开/折叠侧边面板                   |
| 工具箱     | 打开/关闭工具箱弹出菜单             |
| 全局搜索   | 打开全局搜索叠加层                  |
| 主题       | 切换亮色/暗色模式                   |
| 禅模式     | 开启/关闭禅模式（隐藏页面无关元素） |
| 滚动到顶部 | 加载完整历史并跳转到顶部            |
| 锚点       | 返回上次保存的位置                  |
| 滚动到底部 | 跳转到对话底部                      |

在 **设置 → 通用 → 快捷按钮** 中可以调整各按钮的显示状态和顺序。

### 返回锚点

点击**滚动到顶部**或**滚动到底部**时，Ophel 会保存当前位置为锚点。再次点击**锚点**按钮可跳回保存位置。再点一次会在锚点和当前位置之间切换，方便上下来回跳转。

## 工具箱菜单

点击浮动按钮中的工具箱图标（☰），弹出快捷操作菜单：

- **导出** — 导出当前对话到文件
- **复制 Markdown** — 将对话以 Markdown 格式复制到剪贴板
- **移动到文件夹** — 为当前对话指定文件夹
- **设置标签** — 给当前对话添加或修改标签
- **滚动锁定**（切换） — 生成中固定滚动位置
- **模型锁定**（切换） — 锁定指定模型（见模型锁定章节）
- **清理书签** — 删除大纲中指向不存在内容的幽灵书签
- **设置** — 打开设置面板

哪些项目出现在工具箱中，可在 **设置 → 通用 → 工具箱菜单** 中配置。

## 幽灵穿透模式

如果面板挡住了需要点击的内容，按住 **Ctrl**（Windows/Linux）或 **Command**（Mac），保持约 0.2 秒（不能同时按其他键），面板变透明并允许鼠标穿透。松开按键后恢复正常。

## 面板行为设置

设置 → 通用 → 面板：

| 设置项   | 说明                                     |
| -------- | ---------------------------------------- |
| 默认打开 | 进入支持站点时是否自动打开面板           |
| 默认侧边 | 面板显示在左侧还是右侧                   |
| 边缘距离 | 面板距屏幕边缘的默认像素距离             |
| 面板宽度 | 面板宽度（200–600 px）                   |
| 面板高度 | 面板高度占视口的比例（50–100 vh）        |
| 自动隐藏 | 点击面板外区域时是否自动关闭面板         |
| 边缘吸附 | 拖近屏幕边缘时自动吸附；悬停边缘弹出预览 |
| 吸附阈值 | 触发吸附的距离（px）                     |

## 全局搜索

按 **Ctrl+K**（或配置的快捷键，或双击 Shift）打开全局搜索叠加层，可搜索：

- 当前对话的大纲节点
- 所有会话（按标题、标签、文件夹）
- 提示词（按标题或内容）
- 设置项（按名称或关键词）

**语法过滤**：

- `folder:工作` — 查找在"工作"文件夹中的会话
- `tag:研究` — 查找带"研究"标签的会话
- `site:claude` — 查找来自 Claude 的会话

用方向键导航结果，按 Enter 跳转，按 Esc 关闭。

**设置 → 全局搜索**：

- 是否启用双击 Shift 触发
- 是否开启模糊搜索
- 在提示词搜索结果按 Enter 时的行为（插入 or 只定位）

## 布局控制

设置 → 站点设置 → 布局：

**页面宽度覆盖** — 自定义 AI 页面内容区域的最大宽度（% 或 px），适合超宽屏用户。

**用户问题宽度** — 自定义你的问题气泡最大宽度（% 或 px）。

**禅模式** — 隐藏侧边栏、顶部导航等无关元素，专注对话。可用禅模式按钮或快捷键（默认 `Ctrl+Shift+Z`）切换。

## 滚动锁定

启用后，AI 生成内容时页面不会自动滚动到底部，让你保持在当前阅读位置。在工具箱中切换，或使用快捷键（默认 `Alt+S`）。

## 阅读历史

设置 → 功能 → 阅读历史：

| 设置项       | 说明                                     |
| ------------ | ---------------------------------------- |
| 记录阅读位置 | 是否开启位置记录                         |
| 自动恢复     | 重新打开对话时是否自动滚动到上次位置     |
| 保留天数     | 历史记录保留时长（1/3/7/30/90 天或永久） |

## 标签页管理

设置 → 功能 → 标签页（及提醒子标签）：

| 设置项           | 说明                                             |
| ---------------- | ------------------------------------------------ |
| 在新标签打开     | 新建对话时是否在新浏览器标签打开                 |
| 自动重命名标签页 | 将浏览器标签页标题与对话标题同步                 |
| 标题更新间隔     | 检查标题变化的频率（秒）                         |
| 标题格式         | 模板，支持 `{title}`、`{status}`、`{model}` 变量 |
| 显示状态图标     | 生成中在标签页标题中显示旋转/对号图标            |
| 完成通知         | AI 生成完成后发送桌面通知                        |
| 通知音效         | 完成时播放音效                                   |
| 音效预设         | 内置多种提示音可选                               |
| 音量             | 通知音量（0–100%）                               |
| 重复次数与间隔   | 音效重复播放次数和间隔时长                       |
| 已聚焦时通知     | 当前标签页已激活时是否也发送通知                 |
| 自动聚焦窗口     | 生成完成后将浏览器窗口置于前台                   |
| 隐私模式         | 将标签页标题替换为自定义文字                     |
| 隐私标题         | 隐私模式下显示的替代文字                         |

## 高级模型用量统计

对于有每日使用次数限制的 AI 模型（如 Gemini Advanced），Ophel 可在本地统计你的使用量。

设置 → 功能 → 提醒 → 用量监控：

- **启用** — 开启计数小组件
- **每日限额** — 设置预期上限（用于进度可视化）
- **自动重置** — 每天 0 点自动清零

计数器显示今日使用次数、估算 Token 量（输入、输出、往返）以及进度条，出现在支持站点的输入框附近。

## 模型锁定

每次打开指定 AI 站点时，自动切换到你指定的模型，无需手动选择。

设置 → 站点设置 → 模型锁定：

选择站点，输入目标模型名称。Ophel 会在每次页面加载时自动切换。如果模型不可用，什么都不会发生。

支持站点：Gemini、Gemini Enterprise、AI Studio、ChatGPT、Claude、Grok、通义千问、Qwen Studio、元宝、ima、Z.ai。

## 内容增强

设置 → 功能 → 内容：

| 设置项                 | 说明                                        |
| ---------------------- | ------------------------------------------- |
| 用户问题 Markdown 渲染 | 在你的问题气泡中渲染 Markdown 格式          |
| 双击复制 LaTeX         | 双击数学公式复制其 LaTeX 源码               |
| 公式分隔符转换         | 复制时自动转换 `$$...$$` 与 `$...$` 格式    |
| 复制 Markdown 表格     | 为 AI 回复中的表格添加一键复制按钮          |
| AI 回复 Mermaid 渲染   | 尝试渲染 AI 回复中平台未渲染的 Mermaid 图表 |

## 站点专属设置

设置 → 站点设置 → （选择站点）：

### Gemini / Gemini Enterprise

- **Markdown 修复** — 修复粗体文字不能正常渲染的问题
- **去水印** — 去除导出图片上的"由 Gemini 创作"水印（需要 `<all_urls>` 权限）
- **策略重试**（仅 Enterprise） — 自动重试被企业内容策略拦截的请求，可设置最大重试次数

### AI Studio

- **折叠左侧导航栏** — 加载时自动收起左侧导航
- **折叠运行设置面板** — 自动折叠页面右侧的运行设置
- **折叠工具面板** — 自动折叠运行设置中的工具选项
- **折叠高级选项面板** — 自动折叠高级选项区域
- **默认开启搜索工具** — 新建项目时自动开启 Google 搜索工具
- **去水印** — 去除生成图片的水印
- **Markdown 修复** — 修复粗体渲染问题

### ChatGPT

- **Markdown 修复** — 修复粗体文字渲染问题

### Claude — Session Key 管理

Claude 每个账号有使用限额。Ophel 支持存储多个 Session Key（每个对应一个账号），在触及限额时一键切换账号。

在 **设置 → 站点设置 → Claude** 中：

- 手动添加，或点击"导入当前会话"自动获取浏览器中的 Session Key
- 对单个 Key 或全部 Key 做有效性测试
- 将 Key 列表导出/导入为 JSON 文件（备份用）
- 设置当前激活的 Key

使用快捷键**切换 Claude Key**（默认 `Ctrl+Alt+S`）切换到下一个可用的有效 Key。

## 备份与同步

设置 → 备份与同步：

**导出** — 将所有 Ophel 数据（会话元数据、提示词、文件夹、标签、设置、Claude Session Key）保存为 JSON 文件。

**导入** — 从 JSON 文件恢复数据，可选择要恢复的数据类别。

**WebDAV** — 配置 WebDAV 服务器实现数据同步。可设置 URL、用户名、密码、同步模式（手动/自动）、同步间隔及包含的数据类别。

## 权限管理

设置 → 权限 中显示 Ophel 已申请和尚未授权的可选权限：

- `notifications` — 桌面通知功能所需
- `cookies` — Claude Session Key 注入所需
- `<all_urls>` — 图片去水印功能所需（需要抓取并转换图片）

可在此页面随时授予或撤销各项权限。
